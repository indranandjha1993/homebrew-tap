# Homebrew Tap

Homebrew formulae for [devvm](https://github.com/indranandjha1993/devvm).

## Install

```bash
brew tap indranandjha1993/tap
brew install devvm
```

## Formulae

| Formula | Description |
|---------|-------------|
| `devvm` | Developer VM manager — 6 languages, 3 databases, Grafana observability, app hosting |
